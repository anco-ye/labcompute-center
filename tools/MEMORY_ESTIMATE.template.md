# 内存估算依据

- 适用任务ID / 程序入口 / 程序版本：
- 估算日期、工具命令：
- 输入表：memory-estimate.json；原始输出：memory-budget.json
- 数据规模、阶段生命周期、实际进程数（线程不乘全部内存）：
- 关键分配来源（代码尺寸 / 官方说明 / 经验假设 / 完整历史执行）：
- 解释器、库、求解器工作区、结果整理是否计入：
- 完整可比执行ID、对应规模/环境/全程峰值（没有则写无，部分运行仅为下界）：
- 未知项（与输入表unquantified一致；无则说明依据）：
- 工具预测RAM / 私有提交峰值：
- 最终manifest RAM / commit、mode、memory_basis：
- 与工具输出不同的原因及增量；若含安全余量，写明且使用budget：
- 状态：临时估计 / 有完整可比实测支撑（静态算术不代表实测准确性）

本说明只用于计算资源申报，不要求额外试跑、重新计算或科学复核。
