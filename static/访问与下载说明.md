# 科研中心访问与下载

校园网内优先访问 https://192.0.2.30:8443/ ，大文件从此入口下载。
校外或校园网入口不通时，可先访问公网备用入口 https://compute.example.org/ 。公网入口不需要安装 Tailscale，但大文件可能较慢。
https://100.100.0.6:8443/ 是 Tailscale 内网入口，只供已加入相应网络的设备使用，不是通用校园网入口。

## 校园网入口连接超时或被拒绝

1. 确认当前已连接并登录校园网，记录当前 IPv4 地址；同一台电脑换网络后地址可能变化。
2. 使用 VPN、代理的 TUN/增强模式时，把 192.0.2.30/32 设为直连或路由排除；浏览器代理绕过列表包含私网地址，不代表 TUN 路由也已绕过。优先只处理科研中心地址，不全局关闭代理。
3. 服务器已对校园网网卡上的 HTTPS 8443 入口统一放行，不再限制客户端来源子网。任何能通过校园网路由到达该入口的校园设备都可访问，仍须登录平台账号；学校自身的跨网段隔离不由服务器防火墙控制。
4. 联系管理员时提供当前 IPv4、所连网络、访问地址和具体报错；不提供密码。校园网络之间的隔离还可能需要学校信息办处理。

## 证书与下载

校园网入口使用课题组 CA，按准备材料安装并信任经管理员核对的公开 CA；不要跳过证书校验。公网入口使用公网证书。
登录后使用平台的结果下载按钮；下载中断可重试或续传，不需要重新提交计算。单项结果与“打包下载当前已有结果”的范围不同：后者包含批次当前已保存的多个单元结果。

截至 2026-10-19，中心校园网地址为 192.0.2.30。环境目录与准备包会自动同步，但其他人的 VPN、客户端地址变化和学校网络隔离不能由中心保证消除。
